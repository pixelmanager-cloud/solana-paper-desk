## Proposed extension boundary (future admission only)

Require exact extension sets, not a subset, capability summary, allocation length or allowlisted **name**. Validate full base state, owner/program, executable=false, padding/account type, TLV boundaries/types/lengths, duplicates, termination/reserved bytes and every payload; unknown/trailing/noncanonical data fails closed. Decode four-byte COptions strictly, including delegate/allowance consistency and close-authority semantics. Never truncate extended accounts to 82/165 bytes and run the old policy.

## Bounded implementation sequence and acceptance evidence

1. **One offline payload decoder + dedicated tests.** Consume supplied raw mint/account bytes, never provider I/O or summary flags. Implement only IDs18/19/7; explicit presence and bounds, exact schemas/lengths, all authority fields, decimal/raw supply, account owner/mint/state/delegate/close controls. Synthetic source-built positive bytes demonstrate parser structure only. Attack cases: duplicate/hidden/wrong-class TLVs, wrong lengths/types/padding, active pointer/update authorities, foreign metadata mint, oversized/truncated strings, nonempty additional metadata, nonzero tails, dangerous-extension injection and restored account controls. Saved launch remains `RAW_STATE_MISSING`; no fabricated snapshot.
2. **Separate Token-2022 syntax normalization.** Exact operations in the matrix only; require raw bytes and exact ordered accounts, metadata discriminator versus token tag distinction, explicit None versus omission, wrapper argument presence, no extra/multisig signers or suffixes. Keep legacy normalizer unchanged. Tests must distinguish real ImmutableOwner from legacy no-op, pointer authority from metadata update authority, and wrong direct ATA/Pump callers. Parsed saved CPIs remain incomplete witnesses.
3. **Offline structural lifecycle profile, then independent review.** Reuse trace provenance, bind all 16 create accounts, token-program-specific ATA derivation, mode/quote exclusions, exact issuance/revocations and all adverse controls. Preserve unknown caller effects/individual CPI success and opaque mayhem-account semantics. Do not extend the legacy analyzer's acceptance or event schemas by flag substitution.
4. **Coordinator-owned evidence prerequisite before runtime admission.** Trusted finalized raw compiled CPI capture plus same-bank mint/all relevant account bytes, rent/allocation and caller privileges, code-to-program-slot provenance, complete birth-to-cutoff control/transfer histories, exact holder reconciliation and separately verified pool/exit route. Preserve the 18-RPC ceiling, existing account/inspection limits, original records and private loopback.
