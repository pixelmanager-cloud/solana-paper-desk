## What it is
Stdlib-only (urllib) read-only clients with the interface from the queue:
- `RateLimiter(rate, burst)`: thread-safe token bucket (reserve-then-sleep, so concurrent callers stay ordered); `block_for(s)` for Retry-After. Defaults `DEFAULT_RATES`: Helius 10/s, Jupiter 4/s, Kraken 0.5/s (burst 1 => one call per 2s). `backoff_delay(attempt)`: exponential, equal jitter, capped at 8s.
- `Transport`: one provider's path: limiter, bounded retry loop (default 3 attempts inside a 20s deadline; a Retry-After that does not fit the deadline fails fast instead of sleeping), bounded body read, identity-encoding only, no redirects, injectable opener/clock/sleep/rng.
- `ProviderError(code, transient, provider, raw, meta)`: transient = timeout, connection error, HTTP 408/429/5xx, truncated body, Kraken body-level rate limit, stale Kraken trade. Everything else (4xx, auth, redirect, oversize, malformed JSON, bad schema) is non-transient. `raw` carries the response bytes when we have them (malformed or invalid responses), for research retention.
- `Helius(key)`: `.rpc(method, params)` with a read-only method allowlist (no send/sign/simulate/airdrop; refused before any I/O); `.get_multiple_accounts(pubkeys)` (1..100 base58 keys, base64 data decoded, length/shape/owner/lamports checked).
- `Jupiter(key)`: `.quote(in, out, amount, taker)` returns a validated `Quote` (exact u64 amounts, `inAmount` must equal the request, out>0, threshold<=out, route 1..16 hops); `.price(mints)` returns `{mint: Decimal}`, and missing or malformed per-token entries are reported in `meta['missing'|'invalid']` instead of failing the batch (per-candidate isolation).
- `Kraken().sol_usd()`: reuses the desk's pure strict parser `desk.kraken_usd_observation.parse_kraken_usd` (exact URL, single trade, Decimal, freshness). Only that pure parser is imported, no gates, pacing DB or receipts.
- `load_keys(path)`: JSON credential file; must be a regular, non-symlink file with no group/other permission bits; errors are generic (`KEY_FILE_INVALID`).
- Strict JSON: duplicate keys and NaN/Infinity rejected, floats kept exact as `Decimal`.

Every success returns `(parsed, raw_bytes, meta)`; meta has provider, endpoint, http_status, attempts, sent_at, received_at, latency, bytes, raw_sha256.

## Secrets
The key lives only in the outgoing request (Helius `api-key` query parameter, Jupiter `x-api-key` header). Errors are raised `from None` with `__context__` cleared, messages are `provider:CODE`, the logger only records provider/endpoint/attempt/code, and the clients' `repr` is redacted. Tests inject exceptions whose text contains the full request URL (URLError, HTTPError, OSError, RuntimeError) and a provider body that echoes the key, then assert the key is absent from `str`, `repr`, formatted traceback chain, `meta`, DEBUG logs (failure and success paths) and client reprs.

## Limitations
- The TASKS text says to reuse the T37 PriceV3 parser from `desk/usd_valuation.py`; that file is not on `integration/r1` yet, so `price()` has its own small strict parser (positive finite `usdPrice`; it does not check `blockId`/decimals). Swap it for the desk parser when T37 lands if the block-id freshness rule is wanted.
- Jupiter quote uses the desk's `/swap/v2/build` endpoint and field names (`inAmount`, `outAmount`, `otherAmountThreshold`, `routePlan[].swapInfo.label`, `priceImpactPct`). The real response format was not verified against a live call (no live access); `parse_quote` is strict so a format change fails closed as `QUOTE_INVALID` with the raw bytes kept.
- The `Retry-After` header is only parsed as integer seconds (capped 30s).
- The rate limiter is per process and per provider; two lean processes would each get the full allowance.
- Kraken throttling is detected by the literal `Rate limit` in the body.
- `get_multiple_accounts` is capped at 100 keys per call and does not chunk.
- No WebSocket client (the task asked for HTTP clients only).
