## Items
1. **History laundering (HIGH).** `HistoryProgress.advance` no longer catches everything. A failure becomes the pager's RETRYABLE_ERROR state only if
   its retained attempt original proves a transient failure (`failed_reads_transient`: network error, 408/429/5xx); everything else (digest conflict,
   cached-request mismatch, binding invalid, TLS, unclassified/bare OSError, an error without an original, a latching original) propagates, so the
   enclosing pass is classified by its real cause and held. `HISTORY_RECOVERY_REQUIRED` moved from the plain allow-list to `EVIDENCE_CAUSES`; the cycle
   raises it carrying the failed page's original, `classify` is transient for it only with that proof, and `close()` / `_verify()` require it for
   the record. A stale RETRYABLE_ERROR found at entry (no original) holds. Probes are tests through the REAL history path
   (`PaperHistorySource` -> `PaperReadSources` transport with an explicit opener; `tests/test_history_laundering.py`): TLS, bare OSError, ValueError,
   message-only URLError, HTTP 401/403/400, three malformed history pages all HOLD (gate OBSERVATION_RECOVERY_REQUIRED); connection reset, timeout,
   HTTP 429/503/408 close FAILED_CHARGED with the original bound. `test_paper_cycle` history test split (reset closes, bare OSError holds);
   `test_history_progress` failure test now uses an original-proven transient failure.
2. **Dispatcher abandonment (HIGH).** The dispatcher now writes a durable hold (`<journal>.dispatch-hold.<id>`, O_EXCL, fsynced file and directory,
   private) when it stops on a non-transient cause after the intent (deliberate refusal such as the blocked-evidence status, a TLS error behind the
   ambiguous status, an integrity stop). `_recover_unresolved` abandons only when there is no hold (a symlink counts), the owner proof says the owner is
   gone, and no retained `paper_read_attempt_v1` of the intent's scan shows a latching failure (`latching_attempt_for_scan`, newest 20000 pages).
   Transient failures still close and write no hold; a SIGKILLed dispatcher is still abandoned.
3. **macOS tests (M1).** `DispatcherClosureTests` inject the lock table (`lock_sources.free`). Linux only: not run on macOS.
4. **Lifecycle fixture (M2).** `test_ops_fresh_start_lifecycle` uses `MISSING_WINDOW_MEASUREMENT:net_buy_ratio`.
5. **L1** `sqlite3` imported in `paper_history_preparation`. **L2** "Captured history changed" is inside the held try (pass holds). **L3** recovery
   checks sentinels over the same rowid-ordered set as `pending`. **L4** `paper_cycle` writes the hold sentinel BEFORE saving the result whenever the pass
   cannot be closed (`closure.result_requires_hold`); a forked-child kill between result and hold no longer leaves an abandonable pass. **L5** the budget
   causes (investigation, cycle, page limit) now need their charge window in `_verify` (and so in `close`).

## Limitations
- The dispatcher can only inspect `paper_read_attempt_v1` originals; its own acquisition reads (`helius_rpc`) retain none, so its hold file, not originals, carries that case.
- A hold file that cannot be written (read-only journal directory) leaves the intent abandonable after 900 s; the original error still propagates.
- `latching_attempt_for_scan` scans the newest 20000 evidence pages, not an index.
- macOS not run.
