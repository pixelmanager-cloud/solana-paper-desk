# T30 — Market regime entry filter (`paper_regime_version: 1`)

Branch `cloud/T30`, BASE `origin/cloud/T23` (75c795a). Files: new `desk/regime.py`, `desk/engine.py` (one entry gate + sizing hook + two additive output keys), `tests/test_regime.py`, this report. **`desk/` changed → implementation hash changes.**

## Design
- Opt-in: `paper_regime_version: 1` (any other value → `ValueError`). Optional `paper_regime_policy` overrides (validated; unknown keys refused; thresholds must satisfy `0<=off_enter<off_exit<=caution_enter<caution_exit<=1`). Flag absent ⇒ behavior byte-identical (tested with and without a stray `regime` key in the event; no `regime_state` key appears).
- **Evidence is carried in the event**: `event["regime"] = {version:1, as_of:int<=ts, graduations_per_hour:"…", sol_usd_change_pct:"…", median_forward_return:"…" (optional)}` — decimal strings only, exact shape. The gate is a pure function of (event, saved state, config): no clock, store or provider access (tested with `time.time`/`monotonic` patched to raise, and with JSON restarts between events).
- Score = **minimum** of the present components in [0,1] (graduation rate/`grad_rate_normal`; SOL/USD fall vs `sol_drop_off_pct`; median forward return vs `forward_floor`), so any single bad signal degrades the regime. Defaults: normal 6 grad/h, SOL −5 % ⇒ 0, forward −20 % ⇒ 0, TTL 900 s.
- States with hysteresis (saved as additive state key `regime_state`, accepted by the existing checkpoint validators which only require a key superset): NORMAL→CAUTION <0.50, →OFF <0.25; CAUTION→NORMAL ≥0.60, →OFF <0.25; OFF→(CAUTION/NORMAL) only ≥0.35 (then NORMAL only ≥0.60). CAUTION multiplies the sized amount by 0.5 (after the existing loss-streak halving, before quote rounding and the BELOW_MINIMUM check); OFF rejects `REGIME_OFF`.
- Fail closed: missing evidence ⇒ `REGIME_EVIDENCE_REQUIRED`; stale ⇒ `REGIME_STALE`; future/malformed ⇒ `REGIME_EVIDENCE_INVALID`. Rejections leave `regime_state` unchanged; only valid in-TTL evidence advances it.
- **Exits are never gated**: the gate sits after the `was_open` return in the entry path (test: OFF state, no evidence, position still sells). Fills and rejects carry a `regime` audit record (`state, previous, score, as_of`) only when the flag is on.

## Limitations (honest)
- **Producer not wired.** Nothing attaches `event["regime"]` yet: the event builder lives in `desk/paper_cycle.py`/T01 files (AVOID) and the metrics come from the discovery store, T26 data and Kraken observations. With the flag on and no producer, EVERY entry is rejected `REGIME_EVIDENCE_REQUIRED` (fail closed). Enable the flag only together with a producer. `desk/regime.py` exposes the pure pieces (`score`, `next_state`, `validate_record`) a producer can reuse to precompute/log the same state.
- Hysteresis advances only on entry-candidate events that carry valid evidence, not on every tick.
- Thresholds/scales are unvalidated defaults; they need forward paper data (T26/T29) before tuning, and a tuned policy would be a new config version.
- The market-event schema does not enforce a key whitelist, so `regime` is accepted today; if a later schema tightens events, add `regime` to it.
