# T37G — USD provider failures: transient-only closure

Branch `cloud/T37G`, BASE `471a357` (= `cloud/T37F` merged with `cloud/T22H`). Synthetic fixtures only; no provider, VPS or production
store touched. `desk/paper_pass_closure.py` is NOT edited.

## Problem
T37F made every SOL/USD provider failure a retained value, so a failed Jupiter/Kraken attempt ended an entry as a normal `NO_ENTRY`
and an exit as `FAILED_CHARGED`. That is right for transient outages and wrong for a *fault* (TLS, unclassified, 404, malformed
answer): those were silently retired as normal rejections instead of being held for the coordinator.

## Change
* `desk/usd_valuation.py`: `attempt_fault(record, kraken_measured=)` (None = ordinary), `fallback_measured(records)`, `faulted_scans(load, refs)`,
  `BLOCKER_SOURCE_FAULT = 'SOL_USD_SOURCE_FAULT'` (deliberately NOT in `NORMAL_BLOCKERS`).
  * Ordinary: anything `monitoring_budget._latching_failure` calls transient (transport, deadline, RPC/Kraken provider error, pacing
    deadline, HTTP 408/429/5xx), and a response that is merely stale.
  * Fault: every other failure code/status, and any answer that is malformed (html, extra mints, no blockId, wrong decimals, `{}`...).
  * One exception: Jupiter `HTTP_REJECTED` 401/403 is ordinary only when the SAME scan holds a valid (MEASURED at its own second)
    Kraken observation, so a blocked exit can still sell on the fallback. Verdicts are per scan, never across scans.
* `desk/paper_cycle.py`: a non-COMPLETE v2 pass appends a `SOL_USD_SOURCE_FAULT` diagnostic for each faulted scan, so the T22G closure
  holds it (`INTEGRITY_HOLD`). Regime call now passes `valuation_version=2, source=selected_source`.
* `desk/paper_cycle_no_entry.py`: fault code added to `PRODUCER_INTEGRITY`; `_cited_usd_failure` accepts only ordinary failures; the
  proof refuses (defence in depth, independent of the diagnostic) when any cited Jupiter scan is faulted.
* `desk/regime_producer.py`: with `source == "KRAKEN"` the regime reads the Kraken series only (never switches back to Jupiter).

## Probe table (`tests/test_usd_valuation_failures.py`)
cause x {entry, held exit} x {Kraken up, down}: transport/408/503 -> `NO_ENTRY` (entry) / `FAILED_CHARGED`, no latch; TLS/unclassified/
401/403/404 and the four malformed wires -> `INTEGRITY_HOLD` (Kraken down); with Kraken up the entry completes on the fallback and
only a *blocked* exit with 401/403 + measured Kraken ends terminal. 429 rows are excluded from the "Kraken up" cells (pacing embargo
ends them `FAILED_CHARGED`).
