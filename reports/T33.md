# T33 — Regime evidence producer (`paper_regime_version: 1`)

Branch `cloud/T33`, BASE `origin/integration/r1` plus T30's own commit (cherry-picked as 3757d41; T30 sits on an older T23, so a wholesale merge conflicted). **`desk/` changed → implementation hash changes; rotate store sets.**

## What
- `desk/regime_producer.py` (new): `evidence(research_db, evidence_db, ts, ttl)` returns the T30 evidence record or `None`. It never raises, never calls a provider, never charges a request, and opens both stores `mode=ro`.
  - `graduations_per_hour`: count of `scans.created` in `(ts-3600, ts]` in the research (scan) database, a proxy for observed graduations.
  - `sol_usd_change_pct`: retained Kraken attempt records (`paper_read_attempt_v1`, source/method exact) in the newest 600 evidence pages (<=256 KiB each), each re-parsed with the existing `parse_kraken_usd`. Change is newest vs the OLDEST record in the 2 h window that is at least 1800 s older; `as_of` is the newest acquisition second and must be within the policy TTL of the decision.
  - No usable Kraken history means `None`, which the gate turns into `REGIME_EVIDENCE_REQUIRED`: a rejected entry, fail closed.
- `desk/paper_cycle.py`: in the candidate (non-position) `event_builder`, only when `regime.enabled(cfg)`, attach `event["regime"]` and recompute `event_id` (`paper-market:`+digest, same construction as the adapter), so the evidence is bound into the id and replays are exact. `_config` now validates the flag and policy at load (an invalid regime config is refused at `initialize`/`run_once`, not at the first entry). Exits are untouched.
- `desk/regime.py` (T30 fixes): decimal inputs are bounded (`abs <= 1e12`), and `score` overflow is caught (`ArithmeticError` gives `REGIME_EVIDENCE_INVALID`).
- Flag absent: no code path changes (`regime.enabled` is False, no import of the producer).

## Tests
- `python -m unittest tests.test_regime_producer tests.test_paper_cycle_regime tests.test_regime`: producer (8), cycle hook (5), gate (13), all OK.
  - Deterministic evidence from fixture stores; missing, too-short, stale, failed, foreign and malformed history give `None`; stores are byte-identical after a call (read-only, no charge); producer failure leads to `REGIME_EVIDENCE_REQUIRED` and a real `run_once` with no fill and no position; valid evidence enters and the event's `event_id` equals the recomputed digest; an OFF regime blocks the entry; the flag off still enters with no `regime` key; invalid flag/policy refused at load; overflow/huge magnitudes rejected.
- Fail-first: on BASE `desk.regime_producer` does not exist and the cycle never attaches evidence (flag on means every entry rejected).

Survivor: replacing `except ArithmeticError` in the gate. It is unreachable with bounded inputs and the bounded policy (defence in depth), so no honest test exists.
- Related regression: see the bottom of this file.

## Limitations (honest)
- Graduation rate counts scans created, not verified migrations. It tracks the discovery rate only while the discovery worker is running; a gap in discovery reads as a bad tape (fails toward blocking).
- SOL/USD change needs 30+ minutes of retained Kraken attempts. Kraken is only sampled when a cycle runs under USD valuation v1, so a quiet start rejects entries until history accumulates. This is the intended fail-closed default.
- `median_forward_return` (T26 data) is not produced; the field stays optional.
- Thresholds remain the untuned T30 defaults.
- No live run; fixtures are synthetic (`SYNTHETIC_TEST_ONLY`).
