## What changed
- `desk/usd_valuation.py` (new): version 2 (`usd-valuation-v2`). Jupiter PriceV3 SOL price is primary; Kraken is the cross-check (entry) and fallback (when the primary is missing, malformed, stale or out of range). Strict parse (unique keys, decimals==9, blockId present, price in 0.01..1e6, TTL 10 s). Evidence is rebuilt and re-validated from retained originals on every ledger read.
- Entry: if both sources are usable and differ by more than `usd_divergence_max_fraction` (default 0.01, cap 0.25), the entry is a normal terminal no-entry (`USD_SOURCE_DIVERGENCE` inside `MARKET_PRODUCER_BLOCKED`), never a latch. Cross-check failure means primary-only, recorded as an UNKNOWN fallback with its blockers.
- Held/exit: primary alone; Kraken is fetched only if the primary is unusable. Exits are never blocked by divergence. No usable valuation gives a blocked exit with `SOL_USD_UNAVAILABLE` and the position stays held.
- Budgets: fresh entry reserves 8 requests under v2 (v0: 9, v1: 7); both the failed and the fallback request are charged.
- `desk/paper_cycle.py`, `paper_market_adapter.py`, `kraken_usd_observation.py`, `model.py` (quote_exit validation by saved evidence version), `paper_history_preparation.py`, `history_preparation_rejection.py`, `tools/paper_entry_dispatcher.py`, `tools/ops/fresh_start.py` (accept version 2).
- `desk/monitoring_budget.py`: under v2 a non-transient `jupiter_price_v3` failure no longer latches monitoring `SOURCE_FAILURE` (the fallback covers it).
- New opt-in example `config/experiments/paper-jupiter-kraken-fresh.example.json`; the existing v1 example is untouched.
- v0/v1 behaviour is unchanged (the flag is read only when `paper_usd_valuation_version == 2`).

## Limitations
- Jupiter validity is by acquisition time only; `blockId` is checked for presence, there is no chain-time dating.
- Cross-check failure on entry degrades to primary-only (recorded, not blocked).
- Both providers failing on entry leaves the NULL pass (unproved rejection, existing fail-closed behaviour); same for a blocked exit.
- `paper_empty_history_reconciliation` remains v1-only. The watchlist NOT_YET table does not list the new blockers.
