## What changed
- `tools/ops/backup.py` (`python -m tools.ops.backup --data DIR --destination DIR --label TEXT [--require-quiesced UNIT ...] [--expect-count N]`)
  - Discovers every `*.sqlite` recursively under `--data` (including `discovery/`, `entry-dispatch/`); skips `-wal`/`-shm`/`-journal`/`.lock`.
  - Validates all sources before any copy: regular file, `st_nlink == 1`, canonical (`resolve() == path`), distinct inode; symlinked directories/files refused.
  - Refuses if any `--require-quiesced` unit's ActiveState is not `inactive`/`failed` (injectable runner; empty/unknown state is treated as not quiet).
  - Copies with the sqlite online backup API from a `mode=ro` source; only the copy is switched to `journal_mode=DELETE`; `integrity_check`; files 0600, dirs 0700.
  - Destination must not exist (symlink/dangling symlink included) and its parent must be canonical. On any failure the partially created destination is removed (it is always one this run created).
  - `manifest.json`: label, created UTC, `implementation_hash` of the running code, source path, and per DB: sha256, size, table row counts, schema sha256. `--expect-count` fails on mismatch.
- `tools/ops/verify_backup.py` (`python -m tools.ops.verify_backup DIR`): checks file set equals manifest, size + sha256, `integrity_check` (immutable read-only open so the archive is not touched), table counts and schema sha. Exit non-zero on any mismatch.
- No `__init__.py` added under `tools/ops/` (namespace package, per queue rules). Nothing under `desk/` edited (so the runtime hash is unchanged).

## Limitations
- Per-database consistent snapshots only, not one cross-database transaction (same as the existing backup); correctness for cross-DB consistency relies on `--require-quiesced`.
- Does not check free disk space beforehand (the legacy script did not either); a full disk fails the run and the partial destination is removed.
- Symlink checks are TOCTOU-best-effort (sources are re-validated after copying), assuming quiesced writers.
- Archive-side permissions (0700/0600) are set on what the tool creates; verifier does not enforce them.
