# L04 — lean/strategy.py

Branch `cloud/L04`, BASE `origin/integration/r1` (b89864c). Owned files only: `lean/strategy.py`,
`config/lean/strategy-default.json`, `tests/lean/test_strategy.py`. `desk/` is untouched.

## What changed
Pure, I/O-free, clock-free decision module for the lean trader (Decimal money, replayable):
- `StrategyConfig` — strict versioned JSON (`from_dict`/`load`): unknown or missing keys, NaN/Infinity, bools-as-ints,
  out-of-range values and malformed ladders all raise `ConfigError`. `config_hash` is a sha256 of the raw JSON.
  Defaults equal `config/paper.json` (a test cross-checks every shared value).
- `entry_decision(features, quote, portfolio, cfg)` — `quote=None` is the cheap pre-quote gate and returns
  `BUY(size_sol, quote_required=True)`; with a `RoundTrip(buy, sell)` it re-checks quote freshness/size/consistency and
  the round-trip cost cap (desk formula `(spent - expected_sell + 5*fee)/spent`, slippage on the sell leg).
- `exit_decision(position, mark, quote, now, cfg, *, liquidate, danger, mark_at)` — HOLD / SELL / BLOCKED with the desk
  priority LIQUIDATE > DANGER > STOP > TRAILING_STOP (armed after all 3 rungs) > MAX_HOLD > TIME_STOP (disarmed once
  ratio touched 1.15) > one TAKE_PROFIT rung (1.4/2/3 → 30/30/20% of initial qty, stops 1/1.4/2) per observation.
  `SELL(quote_required=True)` when a sell is triggered but no quote was supplied ("sell quote only when an exit
  triggers"). `position_updates` (peak_ratio, touched_15) are returned even on HOLD/BLOCKED; `after_fill` carries
  stage/stop_ratio to apply after the fill.
- Portfolio gates: max positions 4, 2% equity per position, 8% total exposure, liquidity cap (1.5% × 2 × reserve),
  cash minus fee reserve, daily loss stop 6% (entries) and 10% (`should_liquidate`), loss-streak halving at 4 / pause at 6,
  per-mint cooldowns (7200 s after STOP, else 1800 s), one entry per calendar minute.
- Helpers: `cooldown_until`, `next_loss_streak`, `new_position_fields`, `sell_quote_tokens`, `roundtrip_cost_fraction`.

## Fail-closed behaviour
Missing/NaN/negative/bool market cap or liquidity → `*_UNKNOWN` skip. Stale, wrong-side, zero, future-dated,
wrong-size or no-route quotes → SKIP/BLOCKED, never an assumed fill. Missing/stale/non-Decimal mark → BLOCKED
(`STALE_OR_UNAVAILABLE_MARK`), except LIQUIDATE/DANGER which still sell. `Position.stop_ratio` is required so a config
change cannot be silently ignored.

## Deliberate differences from desk/engine.py (limitations)
- No entry score, gates, safety/momentum/flow, bundle audit, regime or sellability proof — screening belongs to
  `lean.candidates`; this module only enforces the market-cap/liquidity band on the features it is given.
- Dropped the desk's `risk_per_trade` and daily-risk-budget size limits so per-position size is exactly 2% of equity as
  the task specifies (desk's trade-risk limit would bind at ~1.67%). Daily loss uses equity drawdown vs day-start equity.
- No EXIT_ONLY/LIQUIDATING mode latch: `should_liquidate` is recomputed from the portfolio on each call, so callers
  must pass `liquidate=True` every loop while it holds.
- Slippage is applied here only to the cost estimate and the net-proceeds check; `lean.paper` must apply it to fills
  exactly once (quotes are raw).
- `portfolio.day_start_equity` rollover (UTC day) is the runner's job.
