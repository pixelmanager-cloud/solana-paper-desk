## Per item
1. **Merge of T22H.** Resolved on T22H's structure. The T16F `scan is None` guard of `_preflight`'s reserve check was dropped by the merge; a failing test found it and it is restored (the reserve check only runs before an intent exists).
2. **Post-intent raises become typed terminal results.** A checkpoint or phase overrun after the intent writes `dispatcher_checkpoint_no_entry_v1`; no intent is orphaned. `_check_records` verifies the record.
3. **Classifiers.** `CHECKPOINT_REASONS` / `BUSY_MESSAGES` map to `watchlist.reason_codes`, `counterfactual` (`REJECTED:CHECKPOINT`) and `funnel_report` (`CHECKPOINT:<reason>`).
4. **Caps enforced.** `_Deadline` (SIGALRM) bounds an in-flight request to the phase cap (acquisition 30 s, intake 25 s); `phase.check()` runs outside the `rpc_state` capture and `phase.finish()` runs ahead of T22G's post-acquire raise. A pacing backoff longer than the remaining phase budget ends as `PACING_BACKOFF_EXCEEDS_PHASE_BUDGET` before any request.
5. **Docs.** `docs/MULTI_POSITION.md` sections rewritten.
6a. **Reserve from all sources.** `RESERVE_PASSES` = 155 = 29 timer passes + 60 watcher price triggers + 30 watcher time triggers + 36 checkpoint passes (12 dispatches x 3). `monitoring_required(N, marks=True)` = 155 x (5N+1) + 2: N=4 -> 3257, N=5 -> 4032 (> 3600), so four positions is the most. A legacy 60/hour allowance is refused with `MONITORING_ALLOWANCE_LEGACY_60`; an insufficient one with `MONITORING_RESERVE_INSUFFICIENT`. A dispatch rate bound (12/hour) is enforced from the journal before the intent.
6b. `entry_seconds()` removed (`ENTRY_SECONDS=52` constant). 6c. Stale docstring removed.
6d. **Null observations.** Two consecutive distinct null observations are required before a `*_CLOSED` zero mark; any ordinary answer resets.
6e. Docs recommend source version 2 only.
